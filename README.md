# pairwise-matchmaking-rating

连胜五把后匹配到高两个段位的对手，匹配分和段位各算一套，展示段位和实际匹配池脱节；延迟权重固定 30ms 一档，跨区玩家被强行拉到低延迟池；组队时用队伍平均分，一个高分段带两个新号就能压进低段局；新号定级赛按 1000 分起步，前五把全是碾压局；连败补偿只加隐藏分不加段位，赢了不加星；地域分区在人数少的时段直接合并，150ms 延迟也开；等待时间超过 30 秒就无限放宽分差，最后匹配到跨三个段位；三人组队允许跨两个段位，五排却按平均分算；赛季重置把所有隐藏分归零，老玩家第一把排到新手；匹配池里同一个玩家被重复入队，开局少一个人。gameplay/matchmaking_rating.py 是核心，tests/test_matchmaking_rating.py 15个红。要修的是：统一 MMR；延迟阈值；按最高分；定级隔离；动态 K 值；地域分区；放宽有上限；组队限制；软重置；入队去重。

## 运行

```bash
python -m pytest tests -q
```
